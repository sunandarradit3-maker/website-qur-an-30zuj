# Qur’an Recitation Studio

Premium Vercel-ready Next.js interface for Qur’an reading and recitation practice.

## Included in this first build

- Responsive premium dark/emerald/gold UI
- Qur’an reader layout with Arabic + Indonesian translation
- Surah navigation shell
- Qari studio with reference visualizer and pitch-contour presentation
- Browser microphone recording with noise-suppression constraints
- Recording timer and waveform UI
- Client-side MP3 export using LAME encoder
- Playback controls and speed cycling

## Deploy

Import this repository into Vercel. No environment variables are required for the current demo build.

## Next production layer

Connect a licensed Qur’an content/audio provider for complete 114-surah text, qari MP3 streams, word-level timestamps, and verified recitation metadata. The visual practice engine can then bind its karaoke cursor and analysis to those timestamps.
